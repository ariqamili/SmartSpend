# SmartSpend

SmartSpend is a modern personal finance management application built with SwiftUI. It helps users track income and expenses, manage budgets, monitor savings goals, and gain insights into their financial habits through structured analytics and visualizations.

---

## Features

- User authentication and account management
- Add, edit, and delete income and expenses
- Category-based transaction organization
- Budget tracking and spending limits
- Savings goals management
- Financial statistics and analytics dashboard
- Interactive charts for spending insights (bar, pie, category breakdown)
- Onboarding flow for new users
- Secure token handling using Keychain
- Modular MVVM architecture for scalability

---

## Tech Stack

- Swift
- SwiftUI
- MVVM Architecture
- REST API integration
- Keychain for secure storage
- Custom UI components and charts

---

## Project Structure

- `Auth/` – Authentication and login logic
- `Home/` – Main dashboard and overview
- `Transactions/` – Income & expense management
- `Categories/` – Transaction categorization system
- `Statistics/` – Financial analytics and charts
- `Savings/` – Savings goals tracking
- `User/` – User profile and settings
- `Network/` – API communication layer
- `Shared/` – Reusable UI components
- `Onboard/` – App onboarding flow

---

## Architecture

The application follows the **MVVM (Model-View-ViewModel)** design pattern to ensure separation of concerns, scalability, and maintainability. Each feature module is structured independently for better organization and future extensibility.
